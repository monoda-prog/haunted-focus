# Haunted Focus

> A spooky productivity app that turns focused work into a glowing haunted house.

## Project status

**Planning stage.** This repository currently contains a project outline and proposed requirements and design. There is no runnable application, implemented feature, test suite, or performance result yet.

Haunted Focus is a proposed project for the Kiroween Costume Contest. Submission eligibility and completion have not been established.

## Planned experience

- Use a Pomodoro-style focus timer with break reminders.
- Keep a simple task list and view daily focus statistics.
- Light a haunted-house window when a focus session is completed.
- Turn a task's ghost into a star when that task is completed.
- Keep progress readable in a conventional list, with reduced-motion controls so animation is never required to understand progress.
